# API 接口文档

> 后端服务地址：`http://47.94.58.72:8000`（云服务器）或 `http://127.0.0.1:8000`（本地）
> 在线 Swagger：`/api/docs`

---

## Web 接口

### POST /api/analyze

全链路核验：内容提取 + 信源核实。

**请求体**：

```json
{
  "url": "https://www.douyin.com/video/123",
  "input_kind": "auto",
  "mode": "auto",
  "verification_mode": "speed",
  "refresh": false,
  "verify": true
}
```

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `url` | string | 必填 | 内容 URL 或分享文案 |
| `input_kind` | string | `"auto"` | `auto` / `article` / `platform` |
| `mode` | string | `"auto"` | `auto`（自适应）/ `visual`（强制多模态） |
| `verification_mode` | string | `"speed"` | `speed`（快速）/ `quality`（深度思考） |
| `refresh` | bool | `false` | 忽略缓存 |
| `verify` | bool | `true` | 是否执行信源核实 |

**响应**：`AnalyzeResponse`（完整核验结果）

---

### POST /api/analyze/stream

同 `/api/analyze`，SSE 版本。依次发送 `progress` 和最终 `result`/`error` 事件。

---

### POST /api/analyze/upload

多模态文件上传核验。

**请求**：`multipart/form-data`

| 字段 | 类型 | 说明 |
|------|------|------|
| `title` | string | 核验标题 |
| `text` | string | 文字内容 |
| `files` | file[] | 图片/视频/音频文件（最多 12 个） |
| `verify` | bool | 是否执行核验 |
| `verification_mode` | string | `speed` / `quality` |

---

### POST /api/analyze/upload/stream

同 `/api/analyze/upload`，SSE 版本。

---

### POST /api/verify

对已有紧凑主张 JSON 单独执行或重试信源核实。

**请求体**：


## 移动端 Job 接口

### POST /v1/jobs

创建核验任务（链接/文字）。立即返回 `202`。

**请求头**：`X-Device-Id: <设备标识>`

**请求体**：

```json
{
  "source": {
    "type": "shared_url",
    "value": "https://www.douyin.com/video/123",
    "platform_hint": "douyin"
  },
  "mode": "auto",
  "verification_mode": "speed",
  "client_request_id": "uuid-string"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `source.type` | string | `shared_url` / `agent_context` / `upload_bundle` |
| `source.value` | string | URL、文字内容或 bundle ID |
| `source.platform_hint` | string | `douyin` / `kuaishou` / `xiaohongshu` / `bilibili` / `null` |
| `mode` | string | `auto` / `visual` |
| `verification_mode` | string | `speed` / `quality` |
| `client_request_id` | string | 客户端幂等 ID（≥8 字符） |

**响应**：

```json
{
  "job_id": "uuid",
  "status": "queued",
  "created_at": "2026-08-02T12:00:00Z",
  "event_url": "/v1/jobs/{job_id}/events",
  "reused": false
}
```

---

### POST /v1/jobs/upload

创建核验任务（多模态文件上传）。

**请求**：`multipart/form-data`

| 字段 | 类型 | 说明 |
|------|------|------|
| `title` | string | 核验标题 |
| `text` | string | 文字说明 |
| `files` | file[] | 附件（最多 12 个，单文件 ≤50MB，合计 ≤150MB） |
| `mode` | string | `auto` / `visual` |
| `verification_mode` | string | `speed` / `quality` |
| `client_request_id` | string | 客户端幂等 ID |

---

### GET /v1/jobs/{job_id}/events

SSE 阶段事件流。支持 `Last-Event-ID` 断线重连。

**事件格式**：

```
id: 1
event: job-stage
data: {"job_id":"...","sequence":1,"stage":"content_resolving","state":"running","display_text":"正在读取分享内容","elapsed_ms":1234,"progress_hint":8}
```

**事件阶段**：

| stage | 说明 | progress |
|-------|------|----------|
| `content_resolving` | 读取分享内容 | 8 |
| `media_extracting` | 理解视频/字幕/画面 | 22 |
| `claim_structuring` | 提取核心主张 | 42 |
| `evidence_retrieval` | 检索公开来源 | 54-72 |
| `evidence_triage` | 筛选证据关系 | 81 |
| `report_generating` | 综合研判 + 生成报告 | 90-100 |
| `completed` | 核验完成 | 100 |
| `failed` | 核验失败 | 100 |
| `cancelled` | 已取消 | 100 |

**事件类型**（`event_kind`）：

| 类型 | 说明 |
|------|------|
| `stage` | 阶段切换 |
| `thinking_delta` | 模型思考增量 |
| `report_delta` | 报告生成增量 |
| `stream_reset` | 流重置（重试时） |
| `artifact` | 阶段产物（查询计划、证据列表等） |

## 受控内容接口

### POST /v1/controlled-content/exchange

沙盒 grant 兑换代理。后端代替 App 向内容网关兑换 grant。

**请求体**：

```json
{
  "exchange_url": "http://47.94.58.72/v1/grants/exchange",
  "grant_code": "...",
  "audience": "mimotrust_guardian_backend",
  "content_id": "video-001",
  "content_version": "v1"

```

**响应**：内容网关返回的 Manifest。

## 数据模型

### StructuredInformation（紧凑主张 JSON）

```json
{
  "主题": "无籽西瓜食品安全说法核验",
  "主张": [
    { "文本": "使用激素喷洒雌花培育的西瓜，种子会变白失去繁殖能力", "表达": "直接" },
    { "文本": "人工干预培育出的无籽西瓜可能不安全", "表达": "隐含" }
  ]
}
```

`表达` 仅允许 `直接`、`转述`、`隐含`。

### 核验报告结构

```json
{
  "整体判断": { "结论": "部分属实", "摘要": "...", "关键证据": ["E1", "E2"], "传播建议": "..." },
  "叙事分析": { "判断": "存在情绪引导", "方式": ["反问暗示", "标题党"], "说明": "..." },
  "主张核验": [
    {
      "主张编号": "C1",
      "主张文本": "...",
      "表达": "直接",
      "结论": "误导",
      "证据充分度": "充分",
      "说明": "...",
      "不确定性": "...",
      "依据": [
        { "证据编号": "E1", "标题": "...", "链接": "...", "关系": "反驳" }
      ]
    }
  ],
  "待补证据": ["事故画面的原始生成者"],
  "关键证据": ["E1", "E2"]
}
```

### 结论状态

| 状态 | 含义 |
|------|------|
| `属实` | 现有证据充分支持 |
| `部分属实` | 部分支持、部分有差异 |
| `误导` | 事实基础存在，但语境被改变 |
| `证据不足` | 暂时缺少足够证据 |
| `无需核验` | 没有可核验的现实世界主张 |
