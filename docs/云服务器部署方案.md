# 云服务器部署方案

## 服务器信息

| 项目 | 值 |
|------|-----|
| 公网 IP | `47.94.58.72` |
| 系统 | Ubuntu 22.04 LTS |
| 配置 | 4 核 / 7.1 GB RAM / 40 GB 磁盘 |
| Python | 3.10.12（需升级到 3.12） |
| 已占用端口 | 22(SSH), 80(Nginx→8787), 3306(MySQL), 8787(沙盒服务) |
| 可用端口 | 8000（给 MiMo Trust API） |

## 部署策略

使用 `MIMO_JOB_MODE=memory` 模式，**不需要 PostgreSQL / Redis / MinIO**，直接用 Python 进程跑 uvicorn，最简链路。

```
手机 App  →  http://47.94.58.72:8000  →  uvicorn (FastAPI)
                                            ├─ 内存 Job 存储
                                            ├─ MiMo API (外部)
                                            └─ Exa 搜索 (外部)
```

---

## 第一步：服务器环境准备

```bash
# SSH 登录
ssh mimo

# 安装 Python 3.12
sudo add-apt-repository ppa:deadsnakes/ppa -y
sudo apt update
sudo apt install -y python3.12 python3.12-venv python3.12-dev

# 安装 ffmpeg（视频/音频处理依赖）
sudo apt install -y ffmpeg

# 安装 Playwright 系统依赖（抖音解析器需要）
sudo apt install -y libnss3 libatk-bridge2.0-0 libdrm2 libxcomposite1 \
  libxrandr2 libgbm1 libpango-1.0-0 libcairo2 libasound2 libxshmfence1
```

## 第二步：部署项目

```bash
# 在服务器上选择部署目录
mkdir -p /srv/mimotrust
cd /srv/mimotrust

# 从本地推代码（在本地执行）
# scp -r D:/08Projects/2026/MimoTrust/* mimo:/srv/mimotrust/
# 或者用 git clone

# 创建虚拟环境
cd /srv/mimotrust
python3.12 -m venv .venv
source .venv/bin/activate

# 安装依赖
pip install -e ".[dev]"

# 安装 Playwright Chromium（抖音浏览器解析器需要）
python -m playwright install --with-deps chromium
```

## 第三步：配置环境变量

```bash
# 复制模板
cp .env.example .env

# 编辑，至少填写以下两项：
nano .env
```

必须填写：

```env
MIMO_API_KEY=你的MiMo密钥
EXA_API_KEY=你的Exa密钥
MIMO_JOB_MODE=memory
```

其他保持默认即可，`memory` 模式不依赖数据库和 Redis。

## 第四步：开放端口

阿里云安全组需要放行 **8000 端口**（TCP 入方向）。

在阿里云控制台：ECS → 安全组 → 入方向 → 添加规则：
- 协议：TCP
- 端口：8000
- 源：0.0.0.0/0

## 第五步：启动服务

```bash
cd /srv/mimotrust
source .venv/bin/activate

# 前台启动（调试用，Ctrl+C 停止）
uvicorn app.main:app --host 0.0.0.0 --port 8000

# 后台启动（生产用）
nohup uvicorn app.main:app --host 0.0.0.0 --port 8000 > server.log 2>&1 &
```

验证：

```bash
# 在服务器上
curl http://localhost:8000/api/health

# 在本地
curl http://47.94.58.72:8000/api/health
```

预期返回：

```json
{
  "status": "ok",
  "mimo_configured": true,
  "job_mode": "memory"
}
```

## 第六步：Android App 连接

构建时指定服务器地址：

```powershell
cd android
.\gradlew.bat assembleDebug -PMIMO_API_BASE_URL=http://47.94.58.72:8000/
```

APK 生成在 `android/app/build/outputs/apk/debug/app-debug.apk`，安装到手机即可。

## 常用运维命令

```bash
# 查看日志
tail -f /srv/mimotrust/server.log

# 停止服务
pkill -f "uvicorn app.main:app"

# 重启
pkill -f "uvicorn app.main:app"
cd /srv/mimotrust && source .venv/bin/activate
nohup uvicorn app.main:app --host 0.0.0.0 --port 8000 > server.log 2>&1 &

# 查看端口占用
ss -tlnp | grep 8000
```

## 已知限制

| 限制 | 说明 |
|------|------|
| HTTP 明文 | App 已配置 `usesCleartextTraffic=true`，演示可用，生产需加 HTTPS |
| 内存模式 | Job 数据存在内存中，服务重启后丢失 |
| 单进程 | uvicorn 单 worker，高并发需加 `--workers 2` |
| 抖音解析 | 需要服务器能访问抖音，且 Playwright Chromium 正常工作 |
