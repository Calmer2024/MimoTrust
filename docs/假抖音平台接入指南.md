# 受控内容沙盒接入指南

> 本文档指导受控内容沙盒平台如何向"小真核验"App 传递内容，使核验流程正常运行。

## 对接方式

通过 Android 系统分享（`Intent.ACTION_SEND`），将内容以纯文本形式传递。

### Intent 构造

```kotlin
val intent = Intent(Intent.ACTION_SEND).apply {
    type = "text/plain"
    putExtra(Intent.EXTRA_TEXT, "这里放分享内容")
}
startActivity(Intent.createChooser(intent, "分享到"))
```

用户在分享面板中选择 **"小真核验"** 即触发核验。

---

## 分享文本的两种模式

### 模式一：带 URL（推荐）

分享文本中包含一个可访问的链接，后端会自动抓取页面、提取内容并核验。

```
https://www.douyin.com/video/7123456789012345678
```

或带描述文案：

```
来看看这个视频！https://www.douyin.com/video/7123456789012345678
```

**要求：**
- 链接必须是后端服务器能访问到的真实 URL（不能是 `localhost` 或内网地址）
- 可以是真实抖音链接，也可以是你们自己搭的模拟页面
- 链接会自动跳转展开（支持短链如 `v.douyin.com/xxx`）

**适用场景：** 视频、图文轮播、带链接的分享卡片

### 模式二：纯文本

分享文本中不包含链接，后端直接将文字作为待核验内容处理。

```
无籽西瓜是用激素喷洒雌花培育的，种子会变白失去繁殖能力，吃了不安全。
```

**适用场景：** 纯文字帖子、评论截图描述、口播文案、手动输入的待核验内容

## 各内容类型示例

| 内容类型 | 分享文本示例 | 说明 |
|---------|------------|------|
| 视频 | `https://www.douyin.com/video/123` | 后端自动提取视频、字幕、ASR |
| 图文（多图） | `https://www.douyin.com/note/456` | 后端自动下载全部图片并 OCR |
| 纯文字 | `今天看到一个说法，xxx是真的吗？` | 直接交给 LLM 提取主张 |
| 分享口令 | `7.89 pda:/ 这个视频太离谱了 https://v.douyin.com/abc` | 后端自动从文本中提取 URL |

## 平台识别

后端通过关键词自动识别来源平台，用于日志和提示展示：

| 关键词 | 识别为 |
|-------|-------|
| `douyin.com` 或 `抖音` | 抖音 |
| `kuaishou.com` 或 `快手` | 快手 |
| `bilibili.com` 或 `b23.tv` | 哔哩哔哩 |
| `xiaohongshu.com` 或 `小红书` | 小红书 |
| 其他 | 通用网页 |

沙盒的分享文本中包含 `douyin.com` 或 `抖音` 字样即可被正确识别。

---

## 注意事项

1. **只传 `EXTRA_TEXT`**：App 目前只读取纯文本字段，不处理图片、视频等二进制 EXTRA
2. **URL 必须可访问**：后端会实际请求该 URL，确保服务器能连通
3. **不需要额外字段**：平台识别、模式选择等全部由后端自动处理
4. **分享目标 App 名称**：注册的 Activity 标签为 **"小真核验"**，包名 `com.mimotrust.xiaozhen`

## 快速验证

启动后端和 App 后，用 adb 模拟分享：

```bash
# 模拟分享一个链接
adb shell am start -a android.intent.action.SEND -t "text/plain" --es android.intent.extra.TEXT "https://www.douyin.com/video/123" --activity-clear-task

# 模拟分享纯文本
adb shell am start -a android.intent.action.SEND -t "text/plain" --es android.intent.extra.TEXT "无籽西瓜是激素培育的，不安全" --activity-clear-task
```
