# 受控内容沙盒

> 本沙盒是 MiMo Trust 的演示组件，模拟短视频平台的浏览与互动场景，用于完整演示"浏览→评论/转发→自动核验"的闭环。

---

## 概述

沙盒由三部分组成：

| 组件 | 路径 | 说明 |
|------|------|------|
| Flutter App | `sandbox/mimotrust_controlled_content/` | 受控内容 Android 应用 |
| 内容网关 | `sandbox/content_gateway/` | Python 标准库 Mock 网关，管理 grant 签发与兑换 |
| 内容注册表 | `sandbox/content_registry/` | 静态视频索引、Manifest 和本地封面 |

---

## 端到端数据链路

```text
video-001
  → registry.json
  → Content Manifest 1.0
  → POST /v1/context-grants
  → POST /v1/grants/exchange
  → 下载 OSS 视频并校验 SHA-256
  → 拒绝重复兑换
  → Flutter 播放和本地互动
  → comment/share 生成 deferred_grant 候选 Context 2.2
  → MethodChannel
  → Kotlin 显式广播到 com.mimotrust.guardian
  → 用户点击小真悬浮球
  → guardian 显式请求当前前台视频
  → 沙盒签发一次性 grant 并返回 guardian_request Context 2.2
  → guardian 兑换 Manifest、校验视频资产并创建核验任务
```

---

## Context 2.2 协议

### 固定标识

| 项目 | 固定值 |
|------|--------|
| 沙盒 applicationId | `com.mimotrust.controlledcontent` |
| 守护者 applicationId | `com.mimotrust.guardian` |
| MethodChannel | `com.mimotrust.controlledcontent/context` |
| 广播 Action（请求） | `com.mimotrust.intent.action.REQUEST_CONTENT_CONTEXT` |
| 广播 Action（响应） | `com.mimotrust.intent.action.CONTENT_CONTEXT` |
| Context Schema | `2.2` |
| Manifest Schema | `1.0` |
| Provider ID | `mimotrust_sandbox` |
| Audience | `mimotrust_guardian_backend` |

### 固定行为

- 内容类型为 `video`、`audio`、`article`、`rich_article`、`image_gallery`
- 只有打开评论面板时发送 `comment`，打开转发面板时发送 `share`
- 浏览、播放、切页、页面停留、进入后台和恢复前台均不发送上下文
- Payload 不包含评论正文、联系人、用户标识、Cookie 或媒体二进制
- 广播为显式、单向、尽力交付，不提供业务 ACK
- 守护者、网关或媒体不可用时，沙盒继续浏览和互动
- 内容全部由开发者手工上传，不提供任何上传能力

### 主动请求流程

1. 用户点击悬浮球 → 守护者发送带 `request_id` 的显式请求
2. 沙盒收到请求后快照当前内容，申请新鲜 180 秒一次性 grant
3. 返回 `trigger = guardian_request`、`event_id = request_id` 的 Context 2.2
4. 守护者以 3–5 秒超时处理防抖和 `event_id` 唯一约束
5. 只有 `guardian_request` 响应进入后端队列

## 内容网关

Python 标准库实现，无第三方依赖。

### 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/health` | 健康检查 |
| POST | `/v1/context-grants` | 申请 grant |
| POST | `/v1/grants/exchange` | 兑换 grant |
| GET | `/assets/...` | 本地演示资产读取 |

### 启动

```bash
python -m sandbox.content_gateway.server --host 127.0.0.1 --port 8787
```

### Grant 机制

- 默认 180 秒过期且只能成功兑换一次
- 错误码：`GRANT_EXPIRED`、`GRANT_REPLAYED`、`AUDIENCE_MISMATCH`、`CONTENT_MISMATCH`、`CONTENT_UNAVAILABLE`
- 日志只记录 `grant_id`，不记录完整 `grant_code`

### Context 2.2 端到端验收

- 沙盒与守护者同时安装在同一设备
- 用户点击悬浮球 → 沙盒返回 `trigger=guardian_request` 的 Context 2.2
- 守护者兑换 grant → 校验 Manifest 和 SHA-256 → 创建核验任务
- 后端完成下载、ASR、结构化转换和核验输出
- 任务最终状态 `completed`，耗时 8257ms，语音覆盖率 100%
